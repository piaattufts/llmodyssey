# Student guide

Install is in the README if you are running it yourself. In a class, open the link your instructor sent.

1. Optional: take the pre-assessment. It is ten questions and stays on your computer.
2. Start with Token Forge unless your instructor says otherwise.
3. Read the implementation note. It tells you what is calculated and what was written ahead of time.
4. Use a hint if you are stuck. The first hint is a concept, not the answer. Each hint costs one point on that round.
5. You can retry a round. The best score is kept.
6. A game is mastered at 70 percent or the threshold your instructor set.
7. Later tiers open after you master enough earlier games. Practice ahead opens them early.
8. Write the reflection if you want it in the export.
9. Export or delete your data from the progress page.

Nothing in the default app sends your answers to a server.
